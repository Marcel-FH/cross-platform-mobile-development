# cross-platform-mobile-development
Demo App für Technologietrends

Kleine Progressive Web App für das Referat zu Cross-Platform Mobile Development:
zeigt Gerät, Browser und Offline-Fähigkeit und testet die Vibrations-Funktion
des Browsers (Android: ja, iPhone: nein). Keine Berechtigungen, keine Datenspeicherung.

Dateien: `index.html` (App), `manifest.webmanifest` (Installierbarkeit),
`sw.js` (Service Worker für Offline-Betrieb), `icons/`.
